Provenance: Generated by No One, Owned by Everyone, Understood by No One

Artist

N/A

Medium

Blockchain, existential crisis

Price

Priceless / Worthless

Provenance

There is no provenance. There is no artist. There is no artwork. There is a token on a blockchain. The token points to a URL. The URL points to a server. The server points to a file. The file is a black square. The black square is not art. The token is not art. The blockchain is not art. The transaction is not art. The absence of all of these things might be art. We are selling the absence. The absence is priceless. The absence is also worthless. These are the same number.
