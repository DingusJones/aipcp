# AICPP — The Art-ifice Institute of Post-Contemporary Praxis

A parody art website that skewers the art world, AI art hype, classic masterpieces, and the museum-industrial complex.

## Deploy

Static site deployed to GitHub Pages.

## Structure

- `index.html` — Home
- `collections.html` — Collections grid
- `about.html` — About / history / board
- `shop.html` — Merch + membership
- `submit.html` — Open call submissions
- `artwork/` — Individual artwork detail pages (30)
- `css/style.css` — Single stylesheet
- `js/main.js` — Interactions
